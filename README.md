# AMZ搜索词分析系统

亚马逊北美站FBA卖家的智能搜索词分析工具，帮助优化广告投放、识别高转化词、自动否定低效词。

## 功能特性

### 核心功能
- **文件上传与解析**: 支持亚马逊后台导出的CSV/Excel搜索词报告，支持批量上传多个文件
- **多维度数据聚合**: ASIN → 广告活动 → 匹配类型 → 关键词 四层聚合
- **ASIN分析**: 按ASIN标识聚合展示不同ASIN下的搜索词表现
- **规则引擎自动分类**:
  - 高花费零转化词 → 建议否定
  - 高转化词 → 建议手动投放
  - 竞品ASIN → 监控/手动商品定位
- **相关性人工审核** (v2.0):
  - 上传数据后自动检测新词进入审核队列
  - 支持标记相关性（强相关核心词/长尾词、弱相关、太泛、不相关）
  - 人工标记的相关性优先于自动判断
- **AI智能分析**: 基于 Google Gemini 提供相关性建议与待确认项分析
- **AI对话助手**: 意图识别 + 数据查询，调用 Gemini 生成答复与引导选项
- **配置版本管理**: 规则阈值可调整、可回滚
- **报告导出**: 否词/手动词/分析结果导出（Excel/CSV，部分导出需已审核）

### 技术亮点
- 本地SQLite数据库，数据安全
- Streamlit现代化UI
- 以单元测试为主，集成测试脚本待补充
- 实时数据分析，确保数据一致性

## 使用说明

### 1. 上传数据

1. 点击左侧导航 **"文件上传"**
2. 选择或创建产品
3. 上传亚马逊搜索词报告（CSV/Excel）
   - 支持批量选择多个文件同时上传
   - 每个文件自动创建独立的广告活动
4. 预览数据（多文件使用Tabs切换）并确认导入
5. 可勾选导入后自动运行规则分析（默认开启）

### 2. 相关性审核 (v2.0+)

上传数据后，系统会自动检测需要人工审核相关性的搜索词：

1. 点击 **"相关性审核"** 或首页的 **"相关性审核"** 快速操作按钮
2. 查看待审核统计：
   - **待审核总数**: 需要审核相关性的词总数
   - **关键词**: 待审核的关键词数量
   - **ASIN**: 待审核的ASIN数量
3. 在审核列表中对每个词标记相关性：
   - **强相关核心词**: 产品核心关键词，优先手动精准
   - **强相关长尾词**: 长尾但相关，可考虑手动
   - **弱相关**: 关联度低，建议否定词组
   - **太泛**: 泛词不精准，建议否定精准
   - **不相关**: 完全无关，建议否定词组
4. 可获取 **AI建议** 辅助判断
5. 审核后规则引擎会使用你标记的相关性做出更准确的决策

> **工作流程**: 上传CSV → 系统自动运行分析 → 检测到新词创建待审核记录 → 进入相关性审核页面标记 → 规则引擎使用人工标记的相关性

### 3. 查看分析结果

1. 点击 **"搜索词分析"**
2. 选择分析模式：
   - **汇总模式**: 聚合同一关键词在不同活动的数据
   - **按活动模式**: 保留广告活动维度，同一词在不同活动可有不同建议
   - **按ASIN模式**: 按ASIN标识聚合同一关键词在不同ASIN的表现
3. 使用筛选器过滤结果
4. 查看分类统计和详情
5. 点击 **"AI分析待确认项"** 让AI辅助判断
6. 使用 **人工审核勾选框** 标记已审核项目（状态自动保存）
7. 导出否词/手动词默认仅导出已审核项；可用“导出全部结果”导出完整列表

### 4. 执行操作

1. 点击 **"操作清单"**
2. 查看否词清单和手动投放推荐
3. 复制词表或导出Excel/CSV
4. 在亚马逊后台执行操作

### 5. 调整配置

1. 点击 **"系统设置"**
2. 调整规则阈值（如高花费阈值、目标ACOS等）
3. 保存配置
4. 可在版本历史中回滚

### 6. 规则管理 (v0.3.0+)

1. 点击 **"系统设置"** → **"规则管理"**
2. **查看规则**: 展示所有规则及其优先级、条件、状态
3. **添加规则**: 点击 "➕ 添加自定义规则" 创建新规则
4. **编辑规则**: 点击规则行的 "✏️ 编辑" 修改条件或动作
5. **启用/禁用**: 点击 "🔴/🟢" 切换规则状态
6. **删除规则**: 点击 "🗑️ 删除" 移除自定义规则
7. **重新应用规则**: 修改规则后点击 "🔄 重新应用规则" 立即更新分析结果

> **注意**: 重新应用规则会覆盖之前的分析结果，建议先导出备份

### 如何导出亚马逊搜索词报告

1. 登录亚马逊卖家后台
2. 进入 **广告** → **广告活动管理器**
3. 选择要分析的广告活动
4. 点击 **搜索词** 标签
5. 选择日期范围（建议30天或更长）
6. 点击 **导出** 按钮，选择CSV或Excel格式

### 规则阈值

在 **系统设置** → **规则配置** 中可调整（默认值来自当前UI配置与规则默认值）：

**样本量 / CVR 阈值（thresholds）**

| 阈值 | 默认值 | 说明 |
|-----|-------|------|
| 可靠分析最小点击数 | 20 | 点击数达到此值才进行可靠分析 |
| ASIN否定最小点击数 | 6 | ASIN点击数达到此值才考虑否定 |
| ASIN高花费无订单 | $20 | 花费超过此值且零订单则否定 |
| 好转化率 (good_cvr) | 10% | CVR高于此值视为表现好 |
| 差转化率 (bad_cvr) | 5% | CVR低于此值视为表现差 |

**否词 / 手动投放阈值（产品配置）**

| 阈值 | 默认值 | 说明 |
|-----|-------|------|
| 高花费阈值 | $10 | 关键词花费超过此值且零转化则建议否定 |
| 低点击率阈值 | 0.1% | CTR低于此值建议否定 |
| 最小点击数 | 10 | 点击数需达到此值才进行分析 |
| 高ACOS阈值 | 50% | ACOS超过此值建议否定或降低出价 |
| 最小订单数 | 2 | 订单数达到此值才建议手动投放 |
| 目标ACOS | 25% | 低于此值视为表现良好 |
| 最低转化率 | 5% | 转化率低于此值视为表现差 |
| 竞品高ACOS | 40% | 竞品ASIN高ACOS阈值 |

### 自定义规则 (v0.3.0+)

除了调整预置规则的阈值，你还可以创建完全自定义的规则：

| 支持的条件 | 说明 |
|-----------|------|
| `spend_min/max` | 花费范围 |
| `orders_min/max` | 订单数范围 |
| `clicks_min/max` | 点击数范围 |
| `impressions_min/max` | 展示数范围 |
| `acos_min/max` | ACOS范围 |
| `cvr_min/max` | 转化率范围 |
| `ctr_min/max` | 点击率范围 |
| `cpc_min/max` | CPC范围 |
| `sales_min/max` | 销售额范围 |
| `roas_min/max` | ROAS范围 |
| `relevance` | 相关性等级匹配 |
| `relevance_not` | 相关性排除 |
| `is_own_variant` | 自家变体ASIN |
| `is_competitor` | 竞品ASIN |
| `need_ai_judgment` | 需AI判断 |

规则按优先级从高到低执行，首个匹配的规则生效（First-Match-Wins策略）。

## 常见问题

### Q: 如何获取Gemini API Key？
A: 访问 [Google AI Studio](https://makersuite.google.com/app/apikey)，登录Google账号后创建API Key。

### Q: 支持哪些文件格式？
A: 支持CSV和Excel（.xlsx, .xls）格式。系统自动识别中英文列名；如 .xls 解析失败可另存为 .xlsx 再导入。

### Q: 数据存储在哪里？
A: 所有数据存储在本地SQLite数据库（默认 `data/db/app.db`，可用 `DATABASE_PATH` 覆盖），不会上传到云端。

### Q: 如何处理大文件？
A: 建议控制在1万行以内以确保速度。更大文件建议按广告活动拆分后分批上传（当前无强制行数限制）。

### Q: AI分析不可用怎么办？
A: 检查.env文件中的GEMINI_API_KEY是否正确配置。如果API临时不可用，可以先使用规则分析，之后再进行AI确认。

### Q: 如何回滚错误的配置？
A: 在 **系统设置** → **规则配置** → **配置版本历史** 中，点击 "回滚到此版本"。

### Q: 修改规则后如何应用到已有数据？
A: 在 **系统设置** → **规则配置** 中，点击 "🔄 重新应用规则" 按钮，系统会重新分析所有搜索词并更新结果。

### Q: 自定义规则和预置规则有什么区别？
A: 所有规则都支持编辑、启用/禁用和删除；需要恢复默认规则时，可在规则管理中点击“重置为默认规则”。
