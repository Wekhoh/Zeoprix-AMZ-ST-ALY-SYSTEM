# 发布说明（2026-04-11）

## 版本定位

本次版本将产品从“搜索词分析工具”推进为更接近**亚马逊广告运营工作台**的形态，重点不在新增孤立功能，而在于把：

- 上传
- 分析
- 审核
- 执行
- 复盘

收成一条更完整的运营闭环。

---

## 本次主要升级

### 1. 首页升级为运营工作台

首页现在不再只是 KPI 和几个快捷按钮，而是新增了：

- **当前工作状态**
  - 当前阶段
  - 最近一次分析
  - 历史沉淀
  - 数据规模
- **今日最优先 3 个动作**
- **近 30 天趋势概览**
- **搜索词结构概览**
- **最近执行效果**

适合运营每天先打开首页判断：

- 现在处于哪个阶段
- 今天先做哪 3 件事
- 最近趋势是否异常
- 最近一批动作有没有开始见效

### 2. AI 融合升级为工作流副驾驶

AI 不再只是一个聊天框，而是已经嵌进主页面：

- 上传页：AI 导入摘要
- 汇总页：AI 汇总简报
- 按活动页：AI 活动解释
- 按 ASIN 页：AI 归因卡
- 审核页：AI 审核建议
- 操作清单页：AI 执行说明

同时保留侧边栏 Copilot，支持：

- 连续对话
- 等待态
- 自动滚动
- 来源提示
- 页面追问联动

### 3. 执行闭环第一版

操作清单页现在支持：

- 生成否词执行批次
- 生成手动投放执行批次
- 标记已执行
- 保存复盘并标记完成

操作历史现在会按“执行批次”优先展示，而不是只平铺旧动作。

### 4. 复盘能力增强

执行批次现在会记录创建时的 baseline snapshot，并支持：

- 前后对比预览
- before / after / delta
- verdict（改善 / 变化不明显 / 继续观察）
- Top changes（改善线索 / 仍需关注）

首页也会显示“最近执行效果”，方便快速判断最近一批动作有没有开始起作用。

### 5. 数据管理与恢复能力增强

系统设置 → 数据管理 已增强：

- 清除分析结果时会连 **analysis snapshot** 一起删除
- 清空产品运行数据时会删除：
  - search_terms
  - analysis_results
  - manual_reviews
  - analysis snapshots
  - execution batches
- 完整备份现在支持真正导出并恢复：
  - campaigns
  - search_terms
  - analysis_results
  - action_plans
  - manual_reviews
  - analysis snapshots
  - execution batches
  - rule_versions
  - strategy_profiles

## 推荐使用方式

### 每天使用建议

1. 先看首页
   - 当前工作状态
   - 今日最优先 3 个动作
   - 最近执行效果
2. 再去操作清单
   - 生成执行批次
   - 执行
   - 写复盘备注
3. 如果是新一轮数据
   - 去文件上传
   - 导入原始报表
   - 重新运行分析
4. 如果有待拍板内容
   - 去相关性审核

### 新批次导入前建议

如果你准备切换到新的类目、产品或新一轮完整数据：

1. 先去首页看最近执行效果
2. 去系统设置 → 数据管理导出完整备份
3. 再决定：
   - 清除分析结果
   - 或清空所有运行数据

## 当前已知边界

### 1. AI 仍然是建议优先

AI 现在会：

- 解释
- 推荐
- 生成草稿
- 提示下一步

但**不会自动执行广告动作**。  
所有真正执行动作仍需要人工确认。

### 2. 最近执行效果不是严格因果模型

当前 verdict 与 Top changes 是基于：

- 执行批次创建时的 baseline snapshot
- 当前最新 snapshot
- 动作风险等级变化

适合运营复盘，但还不是严格的因果归因引擎。

### 3. 仍有少量 warnings

当前全量回归仍有 2 个 warnings，但不影响主功能与发布评估通过。
