# 运营工作台使用手册

## 适用对象

这份手册面向：

- 亚马逊广告专业运营
- 运营负责人
- 兼职协助执行的同事

目标是让你按“真实运营节奏”使用系统，而不是把它当成一个只会导出表格的小工具。

---

## 一、你每天先看哪里

### 先看首页

首页现在是整个系统的运营工作台，建议每天先看这几个区域：

1. **当前工作状态**
   - 现在是待导入、待分析、待审核、待执行，还是可以复盘
2. **今日最优先 3 个动作**
   - 系统会按当前状态给出最值得先做的动作
3. **近 30 天趋势概览**
   - 快速看花费、订单、销售和 ACOS 是否异常
4. **搜索词结构概览**
   - 看核心词 / 泛词 / 竞品 ASIN / 长尾词结构是否健康
5. **最近执行效果**
   - 看最近一批动作是否开始起作用

> 建议：不要一上来先跳明细页。先看首页，先定“今天先做什么”。

## 二、新一轮数据怎么处理

### 适合场景

- 今天刚导出新的广告报表
- 换了类目或新产品
- 需要基于最新数据重新分析

### 操作顺序

1. 打开 **文件上传**
2. 选择当前产品工作区（或创建新产品）
3. 上传原始报表
4. 看 **AI 导入摘要**
   - 它会告诉你：
     - 当前数据是否足够分析
     - 数据量级大概怎样
     - 下一步建议是什么
5. 运行分析（可自动）

### 如果准备彻底开始新一轮

建议先：

1. 去 **系统设置 → 数据管理**
2. 导出完整备份
3. 再决定：
   - 清除分析结果
   - 或清空所有运行数据

## 三、搜索词分析怎么看

### 汇总模式

适合回答：

- 哪些词最浪费
- 哪些词最值得补量
- 当前主要问题是什么

重点看：

- `AI 汇总简报`
- `优先动作草稿`
- 统计结果与变化摘要

### 按活动模式

适合回答：

- 哪个活动最差
- 哪些活动更值得补量
- 同一个词在不同活动里为什么不一样

重点看：

- `AI 活动解释`
- 活动维度下的动作和证据

### 按 ASIN 模式

适合回答：

- 哪个 ASIN 拖后腿
- 问题像词意图不准，还是页面承接不足

重点看：

- `AI 归因卡`
- ASIN 维度差异

## 四、审核页怎么用

### 适合场景

- AI 低置信度词
- 跨 ASIN 分歧词
- 你想手动拍板最终结论

### 使用方式

1. 打开 **相关性审核**
2. 看：
   - `AI 审核建议`
   - 理由
   - 风险提示
3. 人工给出最终判断

### 建议原则

- AI 是建议，不是最终执行者
- 高花费 / 高分歧 / 低置信度优先审核

## 五、操作清单怎么真正执行

### 适合场景

- 今天准备实际处理一批否词
- 今天准备补一批手动投放

### 推荐流程

1. 打开 **操作清单**
2. 看 `AI 执行说明`
3. 在否词区或手动投放区生成 **执行批次**
4. 填写执行备注
5. 到广告后台完成真实执行
6. 回到系统，把批次标记为：
   - 已执行
7. 过几天重新分析，再回来看复盘结果

## 六、操作历史怎么复盘

### 现在能看到什么

每个执行批次都能看到：

- 批次编号
- 批次状态
- 草稿备注
- 执行备注
- 复盘备注
- 前后对比 / 复盘预览
- verdict
- 改善线索
- 仍需关注

### 怎么理解最近执行效果

#### 出现改善信号
说明：

- 否词压力下降
- 分歧减少
- 更可执行的机会增加

#### 变化不明显
说明：

- 新旧两轮的关键数量变化不大
- 这批动作可能还需要更多观察时间

#### 继续观察
说明：

- 已经有变化
- 但还不够稳定，不能轻易下强结论

## 七、什么时候做备份

### 建议一定做备份的时机

1. 切换到新类目之前
2. 清空数据之前
3. 做大规模规则调整之前
4. 做一轮关键执行前后

### 备份里现在会保存什么

- 产品信息
- campaigns
- search_terms
- analysis_results
- action_plans
- manual_reviews
- analysis snapshots
- execution_batches
- rule_versions
- strategy_profiles

### 恢复方式

可以选择：

- 覆盖当前产品
- 恢复为新产品副本

如果你不确定，推荐：

> **恢复为新产品副本**

这样最安全。

---

## 八、AI 助手怎么用最有效

### 侧边栏 AI 助手适合做

- 跨页面问答
- 总结当前产品问题
- 解释当前结果
- 追问下一步建议

### 不建议完全依赖它做

- 单纯把它当搜索框
- 跳过页面内 AI 直接问一切问题

更高效的方式是：

1. 先在页面里看 AI 卡片
2. 再用侧边栏追问

这样上下文最准。

---

## 九、建议的每日节奏

### 每日 10 分钟流程

1. 打开首页
2. 看：
   - 当前工作状态
   - 今日最优先 3 个动作
   - 最近执行效果
3. 去操作清单生成本轮执行批次
4. 执行后标记已执行
5. 下一轮分析后回来复盘

---

## 十、当前边界

### 这套系统现在已经很适合做什么

- 搜索词分析
- 人工审核
- 执行准备
- 结果复盘
- 备份与恢复

### 还不适合做什么

- 自动直接调用亚马逊广告 API 执行动作
- 严格的因果归因分析
- 完整团队审批流

这些属于后续增强项。
