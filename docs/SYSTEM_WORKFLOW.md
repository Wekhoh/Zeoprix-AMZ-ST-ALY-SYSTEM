# AMZ搜索词分析系统 - 系统工作流说明

## 一、核心概念

### 1.1 分析判定来源
系统采用**规则优先、人工审核辅助、AI建议参考**的分析策略：

| 判定来源 | 置信度 | 说明 |
|---------|-------|------|
| **规则引擎** | 100% | 基于配置的规则自动判定 |
| **人工审核** | 100% | 用户手动标记的相关性/竞争力 |
| **AI建议** | 50-85% | Gemini AI提供的建议（仅供参考） |

### 1.2 关键词 vs ASIN 审核
- **关键词**: 使用**相关性等级**（strong_core, strong_longtail, weak, generic, irrelevant）
- **ASIN**: 使用**竞争力评估**（can_compete, cannot_compete, need_observe）

## 二、数据处理流程

```
CSV上传 → 数据解析 → 数据聚合 → 规则分析 → 生成建议
                         ↓
                   创建待审核记录
                         ↓
                   人工相关性审核（可选）
                         ↓
                   更新分析结果
```

### 2.1 步骤详解

1. **CSV上传** (`upload.py`)
   - 支持批量上传多个CSV/Excel文件
   - 每个文件创建一个独立的广告活动
   - 导入后可选自动运行规则分析（默认开启）

2. **数据解析** (`parser.py`)
   - 自动识别中英文列名
   - 清洗数值数据（去除货币符号、百分号等）

3. **数据聚合** (`aggregator.py`)
   - 按搜索词聚合跨活动数据
   - 计算汇总指标：花费、点击、订单、销售额、ACOS、CVR等

4. **规则分析** (`engine.py`)
   - **第一步**：获取词的相关性等级
     - 优先级：人工标记 > 自动检测 > 默认pending
   - **第二步**：遍历规则列表（First-Match-Wins）
   - **第三步**：生成建议动作

5. **人工审核** (`review.py`)
   - 标记关键词的相关性等级
   - 评估ASIN的竞争力
   - 审核后规则引擎会使用人工标记

## 三、规则引擎工作原理

### 3.1 相关性检测 (`_get_term_relevance`)

```python
优先级顺序：
1. 人工标记（manual_reviews表）
   - relevance 非空即视为人工标记，按 Local/Global 优先级读取

2. 自动检测（product_config配置）
   - 核心词精确匹配 → STRONG
   - 泛词精确匹配 → GENERIC
   - 不相关词检查 → IRRELEVANT
   - 弱相关类目词 → WEAK
   - 汽车相关词 → CAR
   - 核心词子串匹配 → STRONG

3. 默认返回 None（需人工审核）
```

### 3.2 规则匹配 (`_match_rule`)

规则按优先级排序，第一个匹配的规则生效：

| 规则类型 | 优先级 | 条件示例 |
|---------|-------|---------|
| 明显不相关词 | 5 | relevance=irrelevant |
| 弱相关类目词 | 6 | relevance=weak |
| 太泛的词 | 7 | relevance=generic |
| 汽车相关词 | 8 | relevance=car |
| 高花费零转化 | 10 | spend≥10, orders=0 |
| 强相关表现差 | 15 | relevance=strong, clicks≥20, cvr≤5% |
| 低转化高花费 | 20 | acos≥50%, spend≥15, clicks≥20 |
| 高转化词 | 30 | orders≥3, acos≤25% |
| ... | ... | ... |

### 3.3 动作类型

**否定动作**:
- `negative_exact`: 否定精准（用于泛词、汽车词）
- `negative_phrase`: 否定词组（用于弱相关、不相关词）

**手动动作**:
- `manual_exact`: 手动精准投放
- `manual_product`: 手动商品定位（ASIN专用）
- `manual_exact_no_neg`: 手动精准 + 自动先不否
- `manual_exact_with_neg`: 手动精准 + 自动否定
- `manual_product_no_neg`: 手动商品定位 + 自动先不否
- `manual_product_with_neg`: 手动商品定位 + 自动否定

**观察动作**:
- `observe`: 继续观察（样本不足）
- `continue_observe`: 继续观察（样本不足）
- `evaluate`: 评估（需要人工判断）

## 四、页面功能说明

### 4.1 首页仪表盘 (`home.py`)
- **数据概览**: 显示基于规则引擎的分析结果统计
- **待审核提示**: 显示需要人工审核相关性的词数量
- **快速操作**: 跳转到各功能页面

### 4.2 相关性审核 (`review.py`)
- **关键词**: 标记相关性等级（强相关核心词、强相关长尾词、弱相关、太泛、不相关）
- **ASIN**: 评估竞争力（可竞争、不可竞争、待观察）
- **AI建议**: 可获取AI的相关性建议（仅供参考）

### 4.3 搜索词分析 (`analysis.py`)
- **汇总模式**: 聚合同一关键词在不同活动的数据
- **按活动模式**: 保留广告活动维度
- **置信度显示**:
  - 100% = 规则明确匹配
  - 70% = 规则标记为需AI判断
  - 50% = 默认规则或需人工确认相关性

### 4.4 ASIN分析 (`asin_analysis.py`)
- **按ASIN聚合**: 按ASIN标识汇总同一关键词在不同ASIN的表现
- **筛选与对比**: 支持ASIN筛选与跨ASIN对比
- **导出**: 支持按ASIN分析结果与否定清单导出（CSV）

### 4.5 操作清单 (`actions.py`)
- **否词操作**:
  - 关键词精确否定
  - 关键词短语否定
  - ASIN商品否定
- **手动投放**: 推荐手动投放的关键词和ASIN

### 4.6 系统设置 (`settings.py`)
- **规则配置**: 编辑/启用/禁用规则
- **关键词库配置**: 配置核心词、弱相关词、不相关词等
- **阈值配置**: 高花费阈值、目标ACOS等

## 五、AI在系统中的角色

### 5.1 AI的使用场景

1. **相关性建议**（`review.py`中的"获取AI建议"按钮）
   - 用户可以请求AI判断词的相关性
   - AI返回建议的相关性等级和置信度
   - **仅供参考**，最终由用户人工确认

2. **冲突解决**（`analyzer.py`）
   - 当同一个词在不同活动有冲突建议时
   - AI可分析冲突原因并给出建议（函数已实现，当前UI未接入）

3. **聊天助手**（`chat.py`）
   - 关键词意图识别 + 数据查询
   - 调用Gemini生成回答并提供引导选项

### 5.2 AI不参与的部分

- **规则引擎判定**: 完全基于配置的规则
- **数据聚合**: 纯数学计算
- **操作清单生成**: 基于规则引擎结果

## 六、数据计数说明

### 6.1 搜索词记录数 vs 唯一搜索词数

系统中有两个重要的数量概念：

| 计数类型 | 数据表 | 说明 |
|---------|-------|------|
| **原始记录数** | search_terms | 每个CSV文件的每行都是一条记录，同一个词在不同活动中会出现多次 |
| **人工审核词数** | manual_reviews | 去重后的待审核/已审核词集合，数量可能小于唯一搜索词数 |

**示例**（来自当前数据库样本）：
- 上传6个CSV文件，共461行数据 → search_terms表有461条记录
- 其中316个唯一的搜索词 → manual_reviews表有316条记录
- 差值145 = 同一个词出现在多个广告活动中

### 6.2 为什么要去重？

在相关性审核时，只需要对每个**唯一搜索词**审核一次。审核结果会自动应用到该词在所有活动中的分析。

## 七、常见问题

### Q: 为什么某些核心词被标记为"低相关性"？
A: 检查系统设置 → 关键词库配置，确保核心词已添加到`core_keywords`列表。

### Q: 置信度50%是什么意思？
A: 表示该词未被任何明确规则匹配，使用了默认规则。建议进行人工相关性审核。

### Q: 规则修改后如何生效？
A: 在系统设置 → 规则配置中点击"重新应用规则"按钮。

### Q: AI建议和规则结果不一致怎么办？
A: AI建议仅供参考。规则结果是基于您配置的规则产生的。如果AI建议更合理，可以通过人工审核来覆盖规则结果。

## 七、最佳实践

1. **先配置关键词库**
   - 在系统设置中添加核心词、弱相关词等
   - 这是相关性检测的基础

2. **定期审核待审核词**
   - 进入相关性审核页面
   - 标记新词的相关性/竞争力

3. **调整规则阈值**
   - 根据产品阶段调整高花费阈值、目标ACOS等
   - 新品可以设置较高的容忍度

4. **导出前检查操作清单**
   - 确认否词列表不包含核心词
   - 检查手动投放推荐是否合理
